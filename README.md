# Syriatech Store

متجر تقني يعمل على GitHub و Vercel فقط، مع لوحة تحكم عربية تتيح لأي شخص تعديل المنتجات والأسعار والأوصاف ورفع الصور بدون فتح الكود.

- **المتجر:** الصفحة الرئيسية `/`
- **لوحة التحكم:** `/admin.html` (رابطها أيضاً في أسفل المتجر)
- **الطلبات:** تصل عبر واتساب

---

## إدارة المتجر (بدون برمجة)

افتح `https://<موقعك>/admin.html` وأدخل كلمة مرور المدير.

| ما تريد فعله | الخطوات |
|---|---|
| تعديل اسم أو سعر أو وصف | اضغط على المنتج من القائمة → عدّل → **حفظ** |
| تغيير صورة منتج | افتح المنتج → **اختيار صورة من الجهاز** → انتظر "تم رفع الصورة" → **حفظ** |
| إضافة خصم | اكتب السعر الجديد في "السعر الحالي" والسعر القديم في "السعر قبل الخصم" (تُحسب النسبة تلقائياً) |
| إضافة منتج جديد | **+ إضافة منتج جديد** → املأ البيانات → **حفظ** |
| حذف منتج | افتح المنتج → **حذف المنتج** (يمكن استعادته من "المنتجات المحذوفة") |
| التراجع عن تعديل | افتح المنتج → **استرجاع البيانات الأصلية** |
| تغيير رقم واتساب أو البريد | تبويب **الإعدادات** |

المنتج الذي لا صورة له يظهر برسمة تلقائية مميزة تحمل اسم المنتج وعلامته التجارية، إلى أن ترفع صورته الحقيقية.

كل تغيير يُحفظ في Vercel Blob ويظهر في المتجر مباشرة بعد تحديث الصفحة. الصور تُصغَّر تلقائياً في المتصفح قبل الرفع (حتى 1400 بكسل، صيغة WEBP) لتبقى الصفحة سريعة.

---

## الإعداد على Vercel (مرة واحدة)

1. اربط المستودع بمشروع على [vercel.com](https://vercel.com).
2. من **Storage** أنشئ **Blob Store** واربطه بالمشروع (يضيف Vercel المتغير `BLOB_READ_WRITE_TOKEN` تلقائياً).
3. من **Settings → Environment Variables** أضف:

   | المتغير | القيمة |
   |---|---|
   | `ADMIN_PASSWORD` | كلمة مرور الدخول إلى لوحة التحكم |
   | `ADMIN_SECRET` | نص عشوائي طويل لتوقيع الجلسات (مثلاً 40 حرفاً) |

4. أعد النشر (Redeploy).

بدون هذين المتغيرين لن تعمل لوحة التحكم، ويبقى المتجر يعرض المنتجات الافتراضية.

**ملاحظات أمان:** استخدم كلمة مرور طويلة وصعبة التخمين. تغيير `ADMIN_PASSWORD` أو `ADMIN_SECRET` ينهي كل الجلسات المفتوحة فوراً. مدة الجلسة 12 ساعة.

## بنية المشروع

| الملف | الوظيفة |
|---|---|
| `index.html`, `style.css`, `script.js` | واجهة المتجر |
| `catalog.js` | الكتالوج الافتراضي (120 منتجاً) + الأقسام والعلامات التجارية، ودوال الدمج المشتركة |
| `admin.html`, `admin.css`, `admin.js` | لوحة التحكم |
| `product-images.js` | يرسم شكلاً تلقائياً مميزاً لكل منتج بلا صورة، ويتيح ربط صور عبر GitHub |
| `api/products.js` | يعيد تعديلات الأدمن للمتجر (عام، للقراءة فقط) |
| `api/admin.js` | تسجيل الدخول، الحفظ والحذف والاستعادة، الإعدادات، وتوقيع رفع الصور |
| `api/image.js` | يعرض الصور المرفوعة من Vercel Blob الخاص |
| `assets/` | رسومات احتياطية وأيقونة الموقع |

### كيف تُدمج البيانات

`catalog.js` هو الأساس، وفوقه تُطبَّق تعديلات لوحة التحكم المحفوظة في Vercel Blob (`data/store-state.json`):

- `overrides` تعديلات على منتجات الكتالوج الأصلي
- `additions` منتجات أضافها المدير
- `deleted` منتجات مخفية عن المتجر (قابلة للاستعادة)
- `settings` رقم واتساب والبريد الإلكتروني

لذلك يبقى تعديل `catalog.js` من GitHub ممكناً، ويؤثر على كل منتج لم يُعدَّل من لوحة التحكم.

## تشغيل محلي

المتجر صفحات ثابتة: يكفي فتح `index.html` في المتصفح لمعاينة الشكل (ستظهر المنتجات الافتراضية بدون تعديلات لوحة التحكم). لتجربة لوحة التحكم و الـ API محلياً استخدم `vercel dev` مع نفس متغيرات البيئة أعلاه.

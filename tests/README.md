# اختبارات المتجر

اختبارات تعمل محلياً بدون أي خدمة خارجية، وتشغّل نسخة من الموقع مع بديل محلي لـ Vercel Blob.

## التشغيل

```bash
cd tests
npm install          # مرة واحدة (puppeteer-core فقط)
npm test             # يشغّل كل الاختبارات
```

أو اختبار واحد:

```bash
npm run test:lang    # اختبار اللغات الصارم
npm run test:ui      # واجهة المتجر ولوحة التحكم
npm run test:config  # إعدادات النشر على Vercel
npm run test:api     # واجهة الخادم
npm run test:compat  # المقاسات والمتصفحات ولغة الجهاز
```

## ماذا يفحص كل اختبار

| الاختبار | يفحص |
|---|---|
| `config-test.mjs` | صحة `vercel.json`: أن كل نمط في `functions` يطابق دالة لم يأخذها نمط قبله، وأن كل ملف تقرأه الدوال من القرص مُرفق في `includeFiles`، وأن كل تحويل في `rewrites` يشير إلى دالة موجودة |
| `lang-test.mjs` | تطابق مفاتيح اللغات الثلاث، عدم وجود نص مكتوب داخل الكود أو HTML، ترجمة كل عنصر ظاهر، عدم تسرّب لغة داخل أخرى، حفظ اللغة بعد إعادة التحميل |
| `ui-test.mjs` | عرض المنتجات، البحث الفوري، التصفية والترتيب، المفضلة، السلة، صفحة المنتج ورابط المشاركة، لوحة التحكم (تعديل، رفع صورة، حذف واستعادة، نفاد الكمية، الإعدادات) |
| `api-test.mjs` | تسجيل الدخول والجلسات، التحقق من المدخلات، الحفظ المتزامن، رفع الصور، منع الوصول غير المصرّح |
| `compat-test.mjs` | من 320px إلى 1920px، عدم وجود تمرير أفقي، حجم أزرار اللمس، اكتشاف لغة الجهاز، لوحة المفاتيح واللمس |

## ملاحظات

- الاختبارات تحتاج متصفح Chrome أو Edge مثبّتاً على الجهاز.
- لا تتصل بأي خدمة خارجية ولا تعدّل بيانات المتجر الحقيقية: تستخدم مخزناً محلياً مؤقتاً داخل `tests/.blobstore`.
- كلمة مرور الأدمن أثناء الاختبار: `test-pass-123` (محلية فقط).
- `config-test.mjs` يمنع تكرار عطل حقيقي أوقف النشر: نمطان متداخلان داخل `functions` جعلا Vercel يرفض البناء بالرسالة
  `The pattern "api/p.js" defined in functions doesn't match any Serverless Functions inside the api directory`،
  فبقي الموقع يعرض النسخة السابقة رغم نجاح كل الاختبارات محلياً.
- لتجربة بناء Vercel كاملاً على الجهاز قبل الرفع (اختياري، يحتاج إنترنت):

```bash
mkdir -p .vercel
echo '{"projectId":"local","orgId":"local","settings":{}}' > .vercel/project.json
npx vercel build --prod    # يجب أن ينتهي بـ Build completed successfully
rm -rf .vercel
```
